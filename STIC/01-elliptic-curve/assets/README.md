# Recursos institucionales

Los archivos de este directorio se descargaron de sitios oficiales y se
conservan sin recolorear ni deformar.

| Archivo | Procedencia | Nota |
| --- | --- | --- |
| `logos/escom.png` | [Sitio oficial de ESCOM](https://www.escom.ipn.mx/images/logoESCOM2x.png) | PNG oficial usado por el portal de la escuela. |
| `logos/ipn-horizontal.svg` | [Portal oficial del IPN](https://www.ipn.mx/assets/files/main/img/template/header/logo-ipn-horizontal.svg) | Fuente vectorial del encabezado institucional. |
| `logos/ipn-horizontal.pdf` | Derivado local del SVG anterior | Conversión con Inkscape para que `graphicx` lo inserte sin `shell-escape`. |

La [Coordinación de Imagen Institucional del IPN](https://www.ipn.mx/imageninstitucional/identidad-institucional.html)
publica el manual y las variantes oficiales. Antes de usar esta plantilla en un
material de difusión pública, conviene comprobar allí los lineamientos vigentes.
